# 按歌曲设计表演、美术与声音

在本曲的 `STORYBOARD.md` 开头写下一个具体的歌词矛盾、一个可见的动作结果和一种美术方向。方向已有依据时做一版；若两种解读都成立，取同一小节、同一音轨，各做 2–4 秒可比较的试镜。例如“松手”可以是晴天下投出纸飞机，也可以是黑白刻印里两只手逐渐分开。两版应能从构图、动作和叙事重点上区分。样片的耗时也可用于估算整片成本。

## 导演一镜

把开头与结尾画成两格，写清谁的位置、视线、姿势、物件归属或可见空间发生了改变。再选一记真实的声音当接触点，把准备放在它之前，回收放在之后。固定机位也能拍完整事件；纯环境、字或抽象形状可以用同样的方法，让门开、字裂开、光从近处扫到远处。长镜按叙事转折增加动作节点。留白、舞步或副歌动作可有意重复，在分镜里记下表达目的。

新工程的 `API.poseAt(t, keys)` 接受升序的 `[时间, 数值数组]`，每个姿势包含相同数量的通道；时间单位与传入的 t 相同。相同姿势形成停顿，超出两端保持首末姿。示例通道为重心、腕横坐标、腕纵坐标；可以换成字块、车辆或门的参数。`API.actionCue('snare', start, end, 0.62)` 在镜内中段选择离目标最近的候选事件，空轨使用目标位置。关键押韵或指定鼓击可直接写听校的绝对帧号；准备和回收围绕同一个锚点计算。

用一次性形变、遮挡、匹配剪辑强调结果。鞋先压地再蹬起，衣摆晚两个输出帧跟上；同一押韵词在副歌再次出现时，可切到上次动作造成的后果。抽鼓时保持关键轮廓；持续步行的脚可以循环，人物相对场景仍要抵达新的位置。

## 给项目写场景

像素新工程在 `scenes.js` 登记 `window.MV_SCENES.场景名 = {draw(g,u,t,api,cam){…}}`。设 `direction.js` 的 `scene` 作为全曲默认，或给镜头写 `scene: '场景名'`。已有工程的内置背景仍走 `bg`。远中近层、构图和道具按剧情编写；`stage` 是检查动作轮廓的排练空间，完成分镜后用本曲场景替换。可以自行设计天光、人物和材质色阶。单镜的 `look` 覆盖指定材质：切换后回拖同一帧应得到相同颜色。

- 水面分带反射、热浪或舞台光束才需要逐像素运算时，可在该场景的 `async setup(cfg, api)` 创建独立的低分辨率 WebGL 画布，预编译材质；在 `draw` 中以绝对秒设 uniform、绘制、将结果 `g.drawImage` 合入世界画布。给不可用的上下文准备一版二维水纹或光带，或让该镜头明确报错。
- 大幅绕行、穿过建筑、有前后遮挡的体素镜头可在同一接口用本地 Three.js。将依赖和场景代码预打包为一个普通脚本，在 index.html 中用带 src 的 defer 标签、放在装配器之前；Remotion 会按列出的脚本装配。额外贴图、模型或字体需内嵌或由项目显式装配。每帧由 t 设置相机与物体变换，先渲场景再合入；先检查单帧、乱序重渲及无 GPU 的回退。普通二维表演直接画在世界画布上。
- 清晰歌词层最后绘制，局部效果跟随水面、灯或物件；色阶、像素轮廓和字幕在手机尺寸复核。已安装的 xilo 工具可用于独立试镜或效果试验。

## 音效与复核

音效默认静音。仅在叙事声源需要时加入鞋底、纸张、门闩或短促气流。把事件的 t 记为动作对应的成片秒，保留原曲作同响度 A/B。在已安装 xilo 的环境中，可用同一份事件时间生成独立音轨：

```bash
# 音效.json 示例：{"duration":4.8,"events":[{"t":1.50,"sound":"whoosh","gain":0.6}]}
python3 "$HOME/.agents/skills/xilo-opus-video/scripts/audio_tools.py" sfx 音效.json 音效.wav
ffmpeg -i 原曲.wav -i 音效.wav -filter_complex "[1:a]volume=-18dB[fx];[0:a][fx]amix=inputs=2:duration=first:normalize=0" -c:a pcm_f32le 试混.wav
```

试听人声齿音、军鼓和低频是否清楚，按耳朵调整音效推子。显式选择使用试混时，`deliver`、Remotion 的 `--song` 及后续 `rmaster` 都传同一份试混，避免最后换回原曲时丢掉音效。

审片时静音遮住字幕，看人物或道具的首姿、接触与结果，再开声核对。需要定位循环，可截一镜裁出人物运行：

```bash
python3 scripts/video_rhythm.py 成片.mp4 --start 12 --end 16 --crop 480:540:320:180 --loops
```

工具比较同周期和半周期的画面差异，只提示时间段与周期。有意律动也会命中；背景、字幕、快速运镜或过小的主体会干扰检测。记录该段保留或重画的原因。无命中时仍要看带声连续试镜。
