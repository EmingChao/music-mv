# 三种画风：口径、选型、禁区

> 三种风格的差别**不是配色**，而是"这画面是用什么材料做的"。
> 像素是**点阵与色数**，拼贴是**纸片与投影**，蜡笔是**笔迹与纸纹**。
> 判断标准很简单：把画面缩到 200px 宽，还能一眼说出是哪种 —— 否则工艺没做出来。

| | `pixel` | `collage` | `crayon` |
|---|---|---|---|
| 材料 | 320×180 点阵 + ≤24 色 + 抖动 | 一张张撕开的纸 + 胶带 + 投影 | 蜡笔线 + 水彩填色 + 纸纹 |
| 逻辑画布 | **320×180**（竖 180×320），整数放大到 1080p | 直接 1920×1080 | 直接 1920×1080 |
| 时间感 | 12fps 逐格（不是 30fps 平滑） | 12fps 定格抖动（拍纸片动画） | 线条 12fps 抖（boil），填色不抖 |
| 歌词 | 游戏对话框（画面里的 UI） | 撕边纸条 + 两侧胶带 | 手写在画面下方，压着纸纹 |
| 适合的歌 | 电子/游戏感/复古/轻快/中二 | 民谣/怀旧/叙事/童年/手作感 | 抒情/温柔/治愈/成长/叙事 |
| 不适合 | 极慢的挽歌（像素看不出细腻情绪） | 快节奏硬核（纸片跟不上） | 需要科技感的题材 |

---

## 1. `pixel`：16bit 像素游戏

**身份判据（缺一条就不像）**
1. 能数出像素格：任何一条边缘都是**台阶**，没有抗锯齿。
2. 颜色少且有抖动：天空/阴影里有 4×4 Bayer 点阵过渡，不是平滑渐变。
3. **不是 30fps 平滑**：12fps 逐格，动作像游戏 sprite。
4. 有 1px 深色描边把主体从背景里"抠"出来。
5. 画面里有游戏 UI 语汇（对话框、血条、光标、招牌小字）。

**必须遵守**
- 坐标 `Math.round`（否则像素会半格发虚）；`size` 取整。
- 视差三层：远（0.25×机位）/ 中（0.5×）/ 近（1.0×）。人物在"近"层。
- 灯光只用 3 档提亮 + 抖动衰减（不要 `shadowBlur`，会糊成一片）。
- 歌词画在**输出分辨率**的清晰层（`ENGINE.lyric` 收到的 `g` 已经是 1920 画布），配像素风对话框：硬边、3px 描边、禁阴影。
- `ENGINE.text` 只用于 320 空间里 **≥8px** 的小字（招牌/HUD）；中文小于 8px 会糊成一团，宁可不写。

**禁区**：平滑渐变、`globalAlpha` 半透明叠色做雾、模糊阴影、曲线抗锯齿边、非整数缩放。

## 2. `collage`：纸艺拼贴

**身份判据**
1. 每样东西都是**独立的纸**：有厚度（投影）、有边（白纸边）、有纹理（纤维/斑点/条纹）。
2. 撕边不规则：边上有一圈 ±6px 的毛边，不是剪刀直线（剪刀直线只用在"故意裁齐"的元素上）。
3. 有**胶带**：至少一两处半透明胶带压着接缝。
4. 定格感：整体 12fps 抖一下（像逐格拍的纸片动画），不是丝滑补间。

**必须遵守**
- 叠放顺序显式写：每加一个元素就是"往画面上贴一张纸"，**先贴远的、再贴近的**。
- 纸片投影统一方向（右下，offset +8/+10，`rgba(60,45,30,0.22)`），不要东一个西一个。
- 白边 6–10px（`#FFF9EE`，不是纯白）。
- 中文字用**手写/楷体栈**：`"Hannotate SC","HanziPen SC","Kaiti SC","STKaiti"`；正文别用黑体（会瞬间变成"设计海报"）。
- 歌词 = 底部一张撕边纸条，两侧压胶带；纸条高度占画面 12–16%。

**禁区**：平滑渐变天空（要改成"几层纸叠加"）、干净锐利的矢量边、`shadowBlur` 大范围模糊、元素之间没有投影就直接叠。

## 3. `crayon`：扁平绘本 / 蜡笔手绘

**身份判据**
1. 线条像蜡笔：**一条线是 3–5 条抖动的细分线**叠出来的，粗细不均、两头轻中间重。
2. 线条会抖（boil）：每秒 12 次重新抖一遍；**填色不抖**（抖了就闪）。
3. 填色不老实：低透明度多层叠加、会"混色"、**故意涂出轮廓外**一点。
4. 纸纹在底下：整屏有纸张颗粒，颜色不是纯色而是"被纸吸过"的颜色。
5. 轮廓不闭合：留 1–2 处缺口（真手绘不会封死）。

**必须遵守**
- **纯 Canvas2D 手写**（不用 p5、不用 WebGL、不用任何库）。
- 纸底色 `#F7F1E4`，纸纹在 `setup()` 里生成一次并缓存成 pattern。
- 线宽随风：`lineCap:'round'`、`globalAlpha 0.3–0.4`，同一根线画 3 遍。
- 色板走"颜料感"：番茄红 `#D9573F`、赭黄 `#E0A33E`、深靛 `#3A3F63`、灰绿 `#7E9078`、墨 `#2A2B33`、冷紫 `#6B5B8E`。
- 填色用 `globalCompositeOperation='multiply'` 让颜色互相吃。
- 人物轮廓比道具粗一点（视觉重量在主体上）。

**禁区**：纯色平涂、玻璃般锐利的矢量边、`shadowBlur`、任何 WebGL/p5、渐变高光（要有就用纸纹挡一下）。

## 4. 怎么帮用户选（`ask_user_question` 里这么说）

| 用户说 | 推荐 |
|---|---|
| "我想要个可爱/复古/游戏感的" | `pixel` |
| "怀旧、小时候、老照片、手工" | `collage` |
| "温柔、治愈、讲个故事、像绘本" | `crayon` |
| "不知道" | 三个 `templates/<style>/demo` 各渲一张给他看（`./mv.sh stills templates/<style>/demo 1.6`），30 秒的事 |

**样图必须来自 demo，不要为"给用户挑画风"另写新镜头** —— 那是浪费 Token，而且 demo 已经调好了。

---

## 5. 换风格 ≠ 重写分镜

分镜（`STORYBOARD.md`）是**跨风格通用**的：同一张分镜表，换 `engine.js` + `character.js` 就能换风格重做。
所以：**先定分镜再定风格也不迟**；但已经渲了半支再换风格 = 白干（`shots/*.js` 的 `ENGINE.sprite` kind 可能不通用）。

`pixel` 的时间感是 12fps 的，快切（副歌 1.6s/镜）在像素风里**正好**；`collage` 的快切要放到 2.2s 以上，否则纸片还没"贴上去"就被换掉了。

## 6. 复刻别人的风格（可选）

用户给一支参考视频说"照这个做"：

```bash
./mv.sh analyze ref.mp4                       # 节奏/段落
ffmpeg -i ref.mp4 -vf "fps=1/2,scale=480:-1" out/ref_%03d.jpg   # 每 2 秒抽一帧
python3 scripts/contact_sheet.py --images out/ref -o out/ref.jpg # 拼成一张看整体
```
然后写一份 `STYLE-NOTES.md`，只记四件事：**主色 3 个（含 hex）、材料感一句话、机位习惯、歌词怎么放**。
> 别去临摹它的具体画面（那是抄）；临摹它的**材料与配色**，内容仍用你的分镜。教程作者的说法："快不是闪贴图"。
