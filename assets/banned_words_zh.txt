# ============================================================================
# banned_words_zh.txt —— 中文短视频（抖音/B站/小红书）歌词字幕用词分级表
# ============================================================================
# 格式：每行  词 <TAB> 等级 <TAB> 谐音建议
#   · 第三列可留空（用 <TAB> 结尾即可），留空表示「没有现成谐音，工具会退化为星号」
#   · # 开头为注释行，工具会跳过
#   · 匹配是「子串匹配」，所以尽量收多字词；单字词容易误伤（如「最」「死」）
#
# 等级取值（7 类）：
#   dirty      脏话      —— 直接侮辱、性辱骂、国骂本体及其缩写/谐音变体
#   vulgar     低俗      —— 性暗示、身体部位、擦边情色，不构成辱骂但平台限流
#   violence   暴力血腥  —— 致死、见血、自残、凶器描写，抖音对自残自杀零容忍
#   ad         广告法    —— 《广告法》第九条绝对化用语，商用内容必删
#   medical    医疗夸大  —— 疗效承诺、包治、替代药物，属《医疗广告管理办法》红线
#   diversion  导流引流  —— 把观众导去站外/私域，平台最恨的一类
#   platform   平台不鼓励—— 不违规但会被限流、不给流量池的表述
#
# 【判定原则】
#   dirty     ：只要「指向人的侮辱」就收。变体要一起收——拼音缩写（SB/TMD/NMD/CNM）、
#               同音近音（傻逼→煞笔/沙比）、方言（妈卖批）。收的是「可被听出来」的形态，
#               因为审核是机器+人双轨，谐音一样会被识别。
#   vulgar    ：收「性」与「身体」的直接指称；不收音近但无实义的词，避免误伤正常歌词。
#   violence  ：收「结果性」词汇（打死/砍死/血洗/割腕/跳楼），不收「过程性」动作
#               （打/砍/推），否则「推开门」也会被命中。
#   ad        ：只收多字绝对化短语。裸「最」「第一」单字不进表——它们会命中
#               「最后」「第一次」，交给人工复核；工具命中后会提示「需确认语境」。
#   medical   ：收疗效承诺与「替代正规医疗」的表述；普通保健词（如「养生」）不收。
#   diversion ：收导流动作与站外平台名；单纯出现品牌名不一定违规，但字幕里出现
#               「加微信」这类动作词几乎必被判导流。
#   platform  ：收「求互动/搬运/破解」类，属于运营建议而非合规红线。
#
# 【刻意不收：政治敏感 / 涉政涉恐 / 涉未成年人类】
#   这一类的具体词表因地区、时期、平台版本而频繁变动，写死在技能包里既不准也危险
#   （容易过期，也容易被误用成「规避审核」的工具）。正确做法是：
#     · 发布前查平台最新《社区自律公约》《社区规范》的「违法违规」章节；
#     · 歌词涉及历史、民族、宗教、领土、领导人、突发公共事件时，整句改词或删句，
#       不要试图用谐音绕过去——这类内容的审核是人工+关键词双轨，谐音等于加重情节；
#     · 拿不准就整句留白（caption.js 的 blank）或直接换一首歌。
# ============================================================================
